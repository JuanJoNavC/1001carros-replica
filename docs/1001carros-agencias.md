## Uso recomendado en el selector de test drive

- La sede predeterminada solicitada puede presentarse como **1001Carros Cumbayá**,
  usando la dirección oficial anterior.
- Para ordenar realmente por cercanía se necesitan coordenadas verificadas o un
  servicio de geocodificación; la fuente oficial consultada no publica latitud
  ni longitud. Mientras tanto, puede priorizarse por zona del usuario (norte,
  centro, Cumbayá, Chillos o sur de Quito) sin presentar distancias exactas.
- Conviene revalidar estas direcciones antes de producción, ya que el PDF es la
  fuente oficial pública disponible pero no indica fecha de actualización.
